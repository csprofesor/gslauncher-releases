### 📺 TV'ye Nasıl Yüklenir? (Downloader ile)

1. Android TV / Google TV / Mi Box cihazınızda **Downloader by AFTVnews** uygulamasını açın.
2. Arama çubuğuna şunu yazın ve **Go** butonuna basın:
   ```text

   ```
3. İndirme tamamlandığında **Kur / Yükle** butonuna basarak kurulumu tamamlayın.
